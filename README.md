# R Project – Football Data Analysis & Visualization in R

This project focuses on analyzing football match data using R. It includes data cleaning, transformation, visualizations, and a final analytical report summarizing key insights about team performance, referee statistics, goals scored, and seasonal trends.

## 📌 Project Overview
- Analyzes football match datasets (e.g., soccer21-22 season).
- Uses R for data preprocessing, aggregation, and visualizations.
- Generates insights about goals, wins/losses, referee decisions, team performance, and monthly trends.
- Includes a conference-style PDF report summarizing all findings.
